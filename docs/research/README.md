# docs/research

## Overview

Research notes behind Integral's design and data tables: SysEx address
findings, foreign (JV/XP/XV) format mappings, effect parameter layouts, host
and plugin precedents, and device measurements. Most files are Markdown notes
(usually titled with the issue they answer), with JSON/CSV tables beside them.

Two scripts live here. They are research tooling, not shipped code:

- `mfx-param-gen.mjs` generates the per-type MFX parameter tables in
  [`crates/integral-core/src/mfx_params.rs`](/crates/integral-core/src/mfx_params.rs)
  from Roland's INTEGRA-7 Editor model (see `mfx-param-layout.md` and
  `mfx-param-families.md`).
- `xv-mfx-fit-check.py` checks XV MFX types 41-90 in a SysEx corpus against
  their INTEGRA-7 target layouts, to vet `copy_slots` entries in
  `foreign-fx-map.json` (see `foreign-fx-map.md`, Unresolved 1).

Notes by topic:

- Effects: `mfx-param-layout.md` (+ `.csv`), `mfx-param-families.md`,
  `fx-param-layout.md`, `foreign-fx-map.md` (+ `.json`).
- Foreign formats: `jv-patch-format.md`, `xv-patch-format.md` (+ `.csv`),
  `foreign-rhythm-format.md` (+ `.csv`), `xv-svd-format.md`,
  `jv-wave-map.md` (+ `.json`), `jv-xv-roland-pairs.md`,
  `map-check-roland-pairs.md`, `foreign-patch-levels.md`,
  `xv-integra-output-levels.md`.
- Device SysEx and state: `full-backup-sysex.md`, `system-settings-sysex.md`,
  `studio-set-part-gaps.md`, `expansion-virtual-slots.md`, `phrase-preview.md`,
  `wave-names.md`, `lfo-rates.md` (+ `.json`), `audio-output-routing.md`.
- Transport and hosting: `integra-wireless-capture.md` (+ `.pcap`),
  `midi-port-ownership.md`, `webview-plugin.md`, `host-parameter-limits.md`,
  `hardware-plugin-precedents.md`, `plugin-test-host.md`.

## Interface

- `node docs/research/mfx-param-gen.mjs <path-to-mfx_params.rs>` (run from
  the repo root). Writes the region between
  `// BEGIN GENERATED by docs/research/mfx-param-gen.mjs` and
  `// END GENERATED`, then prints `<path>: <n> params, <m> name lists`.
  Emits `MFX_CONTROL_TARGETS`, list-valued display-name statics, and one
  `MFX_<NN>_<NAME>` constant per MFX type, each param tagged with a bare
  `ParameterFamily` variant.
- `xv-mfx-fit-check.py CORPUS`. Walks `CORPUS` for `.syx`/`.mid` files and
  prints, per XV MFX type 41-90: target INTEGRA-7 type, block count, and how
  many blocks fit. For fully fitting types it adds the shifted-slot (+/-1, +/-2)
  fit count and the other INTEGRA-7 types that also fit. Ends with the types
  that have no corpus data.

## Invariants

- `mfx-param-gen.mjs` fetches Roland's model files from a pinned commit of
  `SambaGodschynski/integra7-editor-web` and runs them as-is in a `vm`
  context; it does not parse them. Bump the pin deliberately.
- Every MFX parameter label must resolve to a Parameter family (per-type
  exception, stage rule, whole-label rule, base-name rule, in that order);
  an unclassified label fails the run. The rules mirror
  `mfx-param-families.md` (decisions in
  [#159](https://github.com/sigma/integral/issues/159)).
- The target `.rs` file must contain both generated-region markers, END after
  BEGIN, or the generator throws. Code outside the markers is preserved.
- Per-type Control Assign destination lists must agree; a mismatch fails the
  run.
- `xv-mfx-fit-check.py` reads `mfx-param-layout.csv` and `foreign-fx-map.json`
  from its own directory; keep those beside it. It only considers XV DT1
  messages (Model `00 10`) at `aa bb 02 00` with a full Parameters block.
- An out-of-range value disproves a layout; in-range values do not prove it.
  A type that fits is still checked against the XV-5050 manual before it gets
  `copy_slots`.

## Side Effects

- `mfx-param-gen.mjs`: network fetches from `raw.githubusercontent.com`;
  rewrites the given Rust file in place; output is unformatted until
  `rustfmt` runs.
- `xv-mfx-fit-check.py`: read-only; reads the corpus and the two sibling
  tables, prints to stdout. Running it may leave an untracked `__pycache__/`.

## Verification

No test command covers these scripts. Run them as their headers document:

```sh
node docs/research/mfx-param-gen.mjs crates/integral-core/src/mfx_params.rs
rustfmt --edition 2024 crates/integral-core/src/mfx_params.rs
just check   # the regenerated tables must still build, lint and test

python3 docs/research/xv-mfx-fit-check.py <corpus-dir>
```
